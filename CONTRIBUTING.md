# Contributing

This repository accompanies a scientific manuscript. Changes that alter model structure, medium definitions, analysis code, or manuscript-facing numerical results should be made through a branch/pull request and documented with:

1. the scientific rationale;
2. the exact files changed;
3. the software/solver versions used;
4. regenerated source tables/figures where applicable; and
5. a note describing whether manuscript text or supplementary material must also be updated.

Avoid silently replacing the deposited SBML models or source-data tables. For major model revisions, create a new tagged release so the manuscript-associated version remains reproducible.
