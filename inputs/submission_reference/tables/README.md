# Historical source tables and aliases

These files are retained from the submitted and first-revision packages to preserve reproducibility of the original scripts. Some historical numbering aliases coexist; they are not additional independently numbered current results. The active v2 analyses are under `extended/results/`; `extended/results/supplementary_table_map.csv` maps S35-S48, and the current manuscript cites these explicitly. Do not treat an old `not_rerun` filename as the status of the new community analyses.
