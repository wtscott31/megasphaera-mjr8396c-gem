# Release scope and previous-version removal

This repository intentionally contains **one manuscript-associated computational release: v6**. Complete earlier manuscript snapshots, duplicate revision ZIPs, vendored package builds, redundant downloaded compressed/uncompressed copies, macOS metadata, failed solver outputs, and all TeX compiler temporary files are excluded.

Evidence genuinely originating in the original submitted study or earlier experiments is retained **as source data** under `inputs/submission_reference` or canonical `supplementary/data/Sxx` (not as an alternate v1-v5 package). The older provisional models are not passed off as new v6 reconstructions. The complete archived v6 accepted native community-grid flux matrices and reconstructed intermediates live in the accompanying Zenodo full-data extension.
