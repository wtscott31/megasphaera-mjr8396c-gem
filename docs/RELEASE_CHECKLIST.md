# Pre-publication checklist (author-controlled)

- [ ] Co-authors approve reconstructed-model labeling, figure choices, strain aliases and biological caveats.
- [ ] Select and include a software/model license only with authority from all data/software rights holders.
- [ ] Upload the code folder contents, not the compressed ZIP, to the designated GitHub repository.
- [ ] Upload the **separate full dataset** to Zenodo with the approved license, bibliography, attribution and source files.
- [ ] Replace provisional release wording in the manuscript with actual versioned GitHub URL and Zenodo DOI.
- [ ] Run full environmental reproducibility checks on the author-approved solver environment; compile clean and marked manuscripts once more after any edits.
- [ ] Update the response-letter numerical line ranges if the final clean PDF changes.
- [ ] Confirm experimental/sequence source license compatibility before making each original third-party resource public.
